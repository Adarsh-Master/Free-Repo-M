Phase 1: Hardware Proof of Concept (Temp Plan A)

1. Setup & Initialization

  1. Assemble the Circuit: Wire the MQ-3, LEDs, and Buzzer to the Arduino exactly as detailed in the circuit guide below.
  2. Connect Power: Plug the Arduino into your laptop via the USB cable. Do not disconnect it. The laptop acts as the power supply.
  3. Upload Code: Open the Arduino IDE, paste the Temp Plan A code, select your COM port, and click Upload.
  4. Initialize the Display: Click the magnifying glass icon in the top right of the Arduino IDE to open the Serial Monitor. Set the baud rate to 9600. You will see "Current Gas Level: [Number]" scrolling on the screen.

2. Live Demonstration Strategy

  1. The Pitch: Tell your teacher, "For Phase 1 of our project, we focused on building and validating the data-acquisition node. We needed to prove the core logic—that we can successfully detect invisible ethanol off-gassing before integrating the AI prediction model."
  2. The Baseline: Point to the physical circuit. Note that the Green LED is on and the buzzer is silent. Point to the Serial Monitor on your laptop screen to show the normal ambient air readings (usually between 50 and 150).
  3. The Trigger: Take a small piece of tissue with a drop of alcohol-based hand sanitizer (or open a permanent marker) and hold it near the metal mesh of the MQ-3 sensor.
  4. The Result: The numbers on the laptop screen will instantly spike above 300. The Green LED will turn off, the Red LED will light up, and the buzzer will sound. When you pull the sanitizer away, the system will return to the healthy green baseline.

3. Simplified Components & Circuit

Components

  • Arduino Uno R3 & USB Cable
  • MQ-3 Gas Sensor
  • 1x Red LED & 1x Green LED (with 2x 220Ω Resistors)
  • 1x Active Piezo Buzzer
  • Breadboard & Jumper Wires

Circuit Wiring

  • Power: Arduino 5V to Breadboard (+); Arduino GND to Breadboard (-).
  • MQ-3 Sensor: VCC to (+), GND to (-), AOUT to Arduino Analog Pin A0.
  • Green LED: Anode to D6, cathode through resistor to (-).
  • Red LED: Anode to D7, cathode through resistor to (-).
  • Buzzer: Positive pin to D8, negative pin to (-).

4. Emergency Arduino Code

// Temp Plan A: MQ-3 Sensor Threshold Logic (No DHT11)

const int mq3Pin = A0;
const int greenLed = 6;
const int redLed = 7;
const int buzzerPin = 8;

// Threshold for VOC/Ethanol detection (adjust if needed during testing)
const int gasThreshold = 300; 

void setup() {
  // Start serial monitor to show live data on the laptop screen
  Serial.begin(9600);
  
  pinMode(greenLed, OUTPUT);
  pinMode(redLed, OUTPUT);
  pinMode(buzzerPin, OUTPUT);

  // Initial state: LEDs and buzzer off
  digitalWrite(greenLed, LOW);
  digitalWrite(redLed, LOW);
  digitalWrite(buzzerPin, LOW);
}

void loop() {
  // Read the analog value from the MQ-3 sensor (0 to 1023)
  int gasVal = analogRead(mq3Pin);
  
  // Print to Serial Monitor for the live presentation
  Serial.print("Current Gas Level: ");
  Serial.println(gasVal);

  // Hardware Alert Logic
  if (gasVal > gasThreshold) {
    // Alert State: Danger detected
    digitalWrite(redLed, HIGH);
    digitalWrite(greenLed, LOW);
    digitalWrite(buzzerPin, HIGH); 
  } else {
    // Normal State: Clean air
    digitalWrite(redLed, LOW);
    digitalWrite(greenLed, HIGH);
    digitalWrite(buzzerPin, LOW);  
  }

  // Short delay for sensor stability and readable screen scrolling
  delay(500); 
}
